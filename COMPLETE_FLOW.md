## Step 1: Get Authorize URL
```
GET https://oidc.us-east-1.amazonaws.com/authorize?response_type=code&client_id={client_id}&redirect_uri=http://127.0.0.1:9997/oauth/callback&scopes=codewhisperer:completions%20codewhisperer:analysis%20codewhisperer:conversations%20codewhisperer:transformations%20codewhisperer:taskassist&state={state}&code_challenge={code_challenge}&code_challenge_method=S256
→ 302 → https://view.awsapps.com/start/?callback_url=...&orchestrator_id=...
```

## Step 2: Get Signin URL
```
GET https://portal.sso.us-east-1.amazonaws.com/login?directory_id=view&redirect_url={start_url}
Response: {"redirectUrl":"https://us-east-1.signin.aws/platform/d-9067642ac7/login?workflowStateHandle={uuid}","csrfToken":"{number}"}
```
Set cookie: `loginCsrfToken={csrfToken}` on `.signin.aws` domain

## Step 5: Email Submission (get-identity-user)
```
POST same endpoint
Body: {
  "stepId": "get-identity-user",
  "workflowStateHandle": "{from_step4_response}",
  "actionId": "SUBMIT",
  "inputs": [
    {"input_type": "UserRequestInput", "username": "email@havenhaus.in"},
    {"input_type": "ApplicationTypeRequestInput", "applicationType": "SSO_INDIVIDUAL_ID"},
    {"input_type": "UserEventRequestInput", "directoryId": "d-9067642ac7", "userName": "email@havenhaus.in", "userEvents": [{"input_type": "UserEvent", "eventType": "PAGE_SUBMIT", "pageName": "IDENTIFICATION", "timeSpentOnPage": 1229}]},
    {"input_type": "FingerPrintRequestInput", "fingerPrint": "ECdITeCs:..."}
  ],
  "visitorId": "{uuid}",
  "requestId": "{uuid}"
}
```
Response for NEW user: `{"message":{"errorCode":"ENTITY_DOES_NOT_EXIST",...}}` (400)
Then SPA auto-sends SIGNUP action, then stepId:"" with just username → returns `stepId:"user-signup"` + redirect to `/platform/d-{dir}/signup`

## Key Headers for Execute API
```
Content-Type: application/json
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/146.0.0.0 Safari/537.36
Cookie: loginCsrfToken={token}; platform-ubid={set_by_signin.aws}
```

## Fingerprint Format
- Starts with `ECdITeCs:` followed by base64-encoded data (~2000+ chars)
- Generated by browser fingerprinting library
- Needed for every request
